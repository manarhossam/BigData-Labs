# BigData-Labs
# 📌 NTI Big Data Labs (4-Month Training)

This repository contains my hands-on labs completed during the **NTI Big Data Scholarship (4 months)**.  
It focuses on practicing Hadoop ecosystem tools and applying real-world Big Data concepts in a distributed environment.


## 🚀 Covered Technologies

- Hadoop Ecosystem (HDFS, MapReduce)
- HBase (NoSQL database operations)
- Linux (CentOS environment)
- Big Data fundamentals
- HDFS file system operations
- Batch processing using MapReduce jobs

---

## 💡 Project Overview

This repository demonstrates the practical implementation of Big Data concepts, including:

- Distributed data storage using HDFS
- Data processing using MapReduce
- NoSQL database management using HBase
- Working in a Linux-based Big Data environment
